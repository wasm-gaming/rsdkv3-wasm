# Contract 1.0, standalone package and the engine's own storage folder

2026-11-12 · same migration as rsdkv4-wasm 0.3.0 and blastem-wasm 0.2.0 (their RECORD/ files of the
same name); cross-repo plan in wasm-gaming.github.io `RECORD/2026-11-12.homogenize-engine-integration.WIP.md`.

**Status:** approved by the owner ("dale a blastem y luego a los rsdk"), being implemented.

## Where it is (verified at `4bb8a57`, v0.1.4)

- Legacy `{ manifest, load }`, engine-specs `*`; a stale local copy of the contract (`src/wasm-specs.*`).
- Upstream `Sonic-CD-11-Decompilation` cloned at `--depth=1` HEAD — **not pinned** — and the
  build's Python patches use `str.replace` without checking they matched, so a moved upstream can
  produce a broken engine silently. `emscripten/emsdk:latest` — not pinned.
- Working dir `/data/<namespace>` is in-memory and nothing persists `SData.bin`: **saves are lost**
  on reload. The namespace is not prefixed by the engine (`default/` collides with other engines).
- `reset()` throws; `destroy()` only pauses.

## Changes

1. **Pinned build:** upstream at `d1bbec59` (2026-07-04, the source of the 0.1.4 release),
   submodules at the commits it records; `emscripten/emsdk:4.0.10`; every patch asserts it applied.
   `-sEXPORTED_FUNCTIONS` adds `_emscripten_pause_main_loop`/`_resume_main_loop`.
2. **SDK on contract 1.0:** `Rsdkv3SDK` / `Rsdkv3Play` (`static id = 'rsdkv3'`).
   - config: `devMenu`, `engineDebugMode`, `vsync`, `soundtrack` (0 JP/EU, 1 US), `language`,
     `disableTouchControls` (→ generated `settings.ini`), `jsUrl`, `wasmUrl`;
   - options: none; assets: `data` (Data.rsdk, required), `settings` (settings.ini, optional);
   - storage: `namespace`, `persist`; events: `saves`.
   - Storage `rsdkv3/<namespace>/` via the shared `storagePath()`; `SData.bin` seeded from OPFS
     before boot and mirrored back every 10 s, on pause, on page hide and on destroy.
   - `pause(owner)`/`resume(owner)`: engine pause bridge + SDL audio context; `devMenu` bridge kept.
   - Self-contained ESM (contract runtime in `dist/rsdkv3/`), engine-specs `^0.3.2` dependency.
3. **Repo:** `CLAUDE.md -> AGENTS.md`, `RECORD/`; manifest, `wasm-specs.*`, old demo removed;
   no-build demo; tests; workflows with pinned emsdk; release asset `rsdkv3.tar.gz` with
   `rsdkv3/rsdkv3/`; version 0.2.0.
